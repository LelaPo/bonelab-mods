# Bonelab Mod Sync

Легковесная утилита для синхронизации и шаринга сборок модов PCVR для игры **BONELAB**.

## Возможности
- 📦 **Сборка пака по мнемонической фразе:** создание паков через ссылки mod.io (например, `comet-laser-orbit`).
- ☁️ **Облачный реестр без бэкенда:** использование GitHub Gist для хранения манифестов и реестра.
- ⚡ **Потоковая установка:** скачивание на лету и распаковка архивов напрямую в каталог `Mods`.
- 💾 **Автобэкап:** безопасное создание `.zip` резервной копии перед перезаписью.
- 💬 **Live-трекинг в Discord:** обновление прогресс-бара и чеклиста в Discord-канале через Webhook.

## Установка

1. Склонируйте репозиторий:
   ```bash
   git clone -b rewrite/mod-sync https://github.com/ВАШ_НИК/bonelab-mods.git
   cd bonelab-mods
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Скопируйте шаблон окружения:
   ```bash
   copy .env.example .env
   ```

## Настройка `.env`
Заполните переменные в `.env`:
- `MODIO_API_KEY` — ключ API mod.io (обязателен).
- `MASTER_GIST_ID` — ID гиста со списком паков (`registry.json`).
- `GITHUB_TOKEN` — личный токен GitHub (нужен только для создания паков в режиме автора).
- `DISCORD_WEBHOOK_URL` — ссылка на вебхук Discord (опционально).

## Запуск
```bash
python run.py
```
