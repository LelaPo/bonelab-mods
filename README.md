# 🦴 Bonelab Mod Loader

Неофициальный загрузчик модов для [BONELAB](https://store.steampowered.com/app/1592190/BONELAB/).  
Позволяет синхронизировать коллекции модов (профили) в один клик.

> **⚠️ DISCLAIMER:** Проект не связан с Stress Level Zero. Используйте на свой страх и риск. Моды скачиваются с mod.io.

## ✨ Возможности
*   **Простота:** Двойной клик -> Выбор профиля -> Кнопка "Установить".
*   **Скорость:** Параллельная загрузка, кэширование (не качает то, что уже есть).
*   **Безопасность:** Проверка путей архивов, публичные конфиги (без секретов в exe).
*   **Профили:** Легкое переключение между сборками (например: `PvP`, `Quest`, `Default`).

---

## 🚀 Как пользоваться (GUI)

1.  Перейдите в раздел [**Releases**](../../releases) и скачайте последний `BonelabModLoader.exe`.
2.  Запустите файл.
3.  В поле **"Профиль"** выберите нужную сборку (список подгрузится автоматически).
4.  Нажмите **🚀 УСТАНОВИТЬ МОДЫ**.
5.  Дождитесь сообщения "✅ Готово".

*Программа сама попытается найти папку игры. Если не нашла — укажите путь к `BONELAB/Mods` вручную.*

---

## 💻 Командная строка (CLI)

Для продвинутых пользователей или автоматизации.  
Запустите exe через терминал (PowerShell / CMD):

```powershell
# Установить профиль по умолчанию
.\BonelabModLoader.exe

# Установить конкретный профиль
.\BonelabModLoader.exe --profile pvp

# Только проверить обновления (без скачивания)
.\BonelabModLoader.exe --dry-run

# Показать список всех доступных профилей
.\BonelabModLoader.exe --list-profiles

# Указать свой путь к модам
.\BonelabModLoader.exe --path "D:\Games\Bonelab\Mods"
