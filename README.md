# Bonelab Mod Sync

Легковесный автономный CLI-менеджер и сервис обмена коллекциями модов для игры **BONELAB** (PCVR).

## Основные концепции

- ☁️ **Serverless Cloud Storage (GitHub Gist):** Полностью stateless-архитектура. Исходный код чист от пользовательских данных: постоянные коллекции и сессии раздач хранятся в защищенном мастер-гисте автора.
- 📚 **Управление коллекциями:** Создание постоянных подборок модов в облаке (например, сюжетный кооператив, оружие, карты), редактирование состава и добавление модов по ссылке mod.io.
- ⏳ **Эфемерные раздачи (Share Codes):** Генерация временных ссылок из трех слов (`brave-emerald-falcon`) с настраиваемым сроком жизни (TTL), объединением нескольких коллекций и автоматической дедупликацией модов.
- ⚡ **Установка в 1 клик:** Скачивание и распаковка PCVR-версий модов с mod.io напрямую в каталог игры, поддержка безопасного создания бэкапов и тестового dry-run режима.
- 💬 **Discord Webhook:** Трансляция прогресса скачивания и распаковки модов в реальном времени.

## Быстрый старт

### 1. Установка
```bash
git clone https://github.com/ВАШ_НИК/bonelab-mods.git
cd bonelab-mods
pip install -r requirements.txt
```

### 2. Конфигурация (.env)
Скопируйте пример окружения:
```bash
copy .env.example .env
```

Заполните переменные в `.env`:
```ini
MODIO_API_KEY=your_modio_api_key
MASTER_GIST_ID=your_master_gist_id
GITHUB_TOKEN=your_github_token       # Требуется только для Author Mode
DISCORD_WEBHOOK_URL=                 # Опционально
MODIO_GAME_ID=3809
```

> **Примечание:** Если `GITHUB_TOKEN` не указан, утилита запускается в **Client Mode** (только установка модов по коду раздачи).

### 3. Запуск
```bash
python run.py
```
